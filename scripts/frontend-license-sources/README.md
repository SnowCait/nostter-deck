# Upstream frontend notices

These source documents cover code and data already embedded in npm distributions. The build collects the installed packages' own license files separately.

| Shipped package                   | Upstream documents                                                                                                                                                                                                                                                                                                                                                                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `dexie@4.4.7`                     | `LICENSE` from [`safari-14-idb-fix@3.0.0`](https://registry.npmjs.org/safari-14-idb-fix/-/safari-14-idb-fix-3.0.0.tgz), identified by Dexie's published source map.                                                                                                                                                                                                                                                                  |
| `emoji-picker-element@1.29.1`     | `LICENSE` from [`blob-util@2.0.2`](https://registry.npmjs.org/blob-util/-/blob-util-2.0.2.tgz), identified by the published database source map.                                                                                                                                                                                                                                                                                     |
| `emoji-picker-element-data@1.8.0` | `LICENSE` from [`emojibase-data@17.0.0`](https://registry.npmjs.org/emojibase-data/-/emojibase-data-17.0.0.tgz), the version listed in the published data package.                                                                                                                                                                                                                                                                   |
| `emojibase-data@17.0.0`           | The matching [CLDR 48 annotation distribution](https://registry.npmjs.org/cldr-annotations-full/-/cldr-annotations-full-48.0.0.tgz) and its derived annotation distribution ship the same `LICENSE`. [Unicode Emoji 17.0](https://www.unicode.org/Public/17.0.0/emoji/emoji-test.txt) identifies its copyright and points to the Unicode terms, which specify the [Unicode Data Files license](https://www.unicode.org/license.txt). |

When one of the shipping packages changes version, review the embedded sources in its published files and update the matching entry in [the build plugin](../frontend-licenses.js).
