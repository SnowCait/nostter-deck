# Contributing to nostter-deck

## Issues and discussions

Use GitHub Issues for bug reports, feature requests, and maintenance tasks.

Use GitHub Discussions for questions and broader ideas.

### Issue types

Use issue types to classify issues by their purpose, regardless of the size of the work.

- **Bug**: Fix incorrect or unexpected behavior.
- **Feature**: Add or improve user-facing functionality.
- **Task**: Perform internal or maintenance work, such as refactoring, dependency updates, documentation, or CI improvements.

### Labels

Use labels to provide additional context, such as affected areas or cross-cutting concerns.

Do not use labels to duplicate issue types.
